# Shaikh Obaidullah

Mathematical biology · Department of Mathematics, Florida State University · ORCID [0009-0003-8293-7816](https://orcid.org/0009-0003-8293-7816)

I work on mathematical models of microbial communities and population dynamics. Much of this work asks what a simplified model can and cannot predict.

```
research
├── gut microbiome dynamics      perturbation and recovery, Lotka–Volterra models, compositional data
├── spatial model reduction      habitat–reservoir PDE–ODE models, well-mixed approximations
├── population structure         matrix population models, reproductive timing
└── identifiability              what sparse and compositional data can determine
```
